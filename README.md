# Product Management System

A simple Product Management System built with Django. It helps manage products, categories, stock, and product details.

## Features

- Login and Logout
- Dashboard
- Add, Edit and Delete Products
- Product Categories
- Search and Filter
- Stock Management
- Product Status
- Product Image URL

## Technologies

- Python
- Django
- SQLite
- HTML
- CSS
- Bootstrap

## Run the Project

```bash
python -m venv venv
venv\Scripts\activate
pip install django
python manage.py migrate
python manage.py runserver
```

Open `http://127.0.0.1:8000/` in your browser.
